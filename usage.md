# Manual de Uso do Sistema 📖

Bem-vindo ao manual de uso do **Sistema de Gerenciamento de Finanças**.  
Este documento apresenta as principais funcionalidades do sistema e orienta o usuário sobre como utilizá-las corretamente.

---

# 1. Cadastro e Login

Ao iniciar o sistema, será exibida a tela de **Login**.

- Caso já possua cadastro, informe suas credenciais e clique em **Entrar**.
- Caso seja seu primeiro acesso, clique em **Cadastrar-se** para criar uma conta.

Após o login bem-sucedido, o usuário será direcionado para o **Dashboard (Tela Inicial)**.

---

# 2. Tela Inicial e Navegação

O menu principal permite acessar as seguintes áreas:

- **Dashboard / Início:** Visão geral das finanças do usuário.
- **Adicionar Transação:** Registro de receitas e despesas.
- **Meus Bancos:** Gerenciamento de contas bancárias.
- **Gráficos:** Visualização gráfica dos dados financeiros.
- **Extrato:** Listagem detalhada das transações com opções de filtragem e edição.
- **Exportar Dados:** Exportação de relatórios em PDF ou CSV.
- **Importar Dados:** Importação de arquivos CSV.

---

# 3. Registrando uma Nova Transação

Para adicionar uma receita ou despesa:

1. No **Dashboard**, clique em **Adicionar Transação**.
2. Preencha os campos obrigatórios:
   - **Tipo:** Receita (entrada) ou Despesa (saída).
   - **Valor:** Valor monetário da transação.
   - **Data:** Data da ocorrência.
   - **Descrição:** Exemplo: Salário, Conta de Luz, Aluguel.
   - **Status:** Efetuada ou Pendente.
   - **Categoria:** Exemplo: Lazer, Transporte, Moradia, Salário.
   - **Banco:** Conta bancária associada.
3. Clique em **Salvar**.

A transação será registrada automaticamente no banco de dados local.

---

# 4. Adicionando e Gerenciando Bancos

Para cadastrar um novo banco:

1. Acesse **Meus Bancos** pelo menu.
2. Clique em **Novo Banco**.
3. Preencha:
   - **Nome do Banco**
   - **Saldo Inicial**
4. Clique em **Salvar**.

É possível também marcar bancos como **ativos** ou **inativos**.

---

# 5. Visualizando Gráficos

Acesse a seção **Gráficos** pelo menu principal.

O sistema gera automaticamente representações visuais do fluxo financeiro, permitindo:

- Análise mensal
- Alteração de período
- Alteração do tipo de gráfico

Os dados são atualizados automaticamente ao inserir ou modificar transações.

---

# 6. Importando Arquivos CSV

Para importar dados financeiros em lote:

1. Acesse **Importar Dados**.
2. Clique em **Selecionar Arquivo**.
3. Escolha um arquivo no formato `.csv`.
4. Confirme a importação.

O sistema processará o arquivo e salvará os registros automaticamente.

---

# 7. Exportando Relatórios (PDF e CSV)

Para exportar seus dados financeiros:

1. Acesse **Dashboard** na área de **Extrato**.
2. Clique em **Exportar**.
3. Escolha o formato desejado (PDF ou CSV).

O arquivo será gerado e salvo no seu computador.

---

# Observações Finais

- Todas as informações são armazenadas localmente.
